## Estructura

- `index.html`: página principal.
- `error/`: páginas de error 404 y 403.
- `doc/`: documentación.
- `webroot/`: hojas de estilo, scripts, imágenes y horario.
- `.htaccess`: páginas de error personalizadas.

## Tecnologías

HTML5, CSS3 y JavaScript, servidor Apache.
